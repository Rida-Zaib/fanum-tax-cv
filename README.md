# Fanum Tax CV

An AI tool that taxes the weak spots out of your CV, GitHub, and portfolio,
then recommends the jobs, internships, and skills that fit you best.

## Planned features
- CV review, builder, and enhancer
- GitHub profile analysis
- Portfolio website feedback
- Skills rating and gap analysis
- Job and internship matching
- Course, certificate, and extracurricular suggestions for beginners

## Status
Setup phase. Project scaffolding in progress.
